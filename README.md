# pages

Public static hosting for selected [Project Yeet Cannon](https://github.com/project-yeet-cannon/pyc) projects, published via GitHub Pages.

This repo is a deploy target, not a place for manual edits. Content under project subdirectories (e.g. `binary-clock/`, `imprint/`) is pushed here automatically by a workflow in the private `pyc` repo whenever those projects change on `main`. `index.html` at the root is also regenerated by that workflow.

Live at: https://project-yeet-cannon.github.io/pages/
